# Clothed Vampires — Progress Update, November 14

## What we're building

You reported that your vampire went outside in a burka and was still attacked by the sunlight, even after you took his wings off. You were right that the wings had nothing to do with it. The gene behind it is **vicious UV sensitivity** from Alpha Genes. It doesn't use the normal game's sunlight penalties. It uses Vanilla Expanded Framework's own sunlight effect, which knocks the pawn unconscious, and Clothed Vampires has never covered that. So no clothing could have protected him.

Fixing that is the next step. Before starting it, we tidied up two things the mod needed anyway:

- **RimWorld 1.7 support.** The mod only worked on 1.6. It now ships a build for each version, and the game loads the right one automatically.
- **Player documents.** The mod now has a proper Steam Workshop description and these update notes, kept in the project's public repository.

Nothing about how the mod plays changed in this round. A dressed vampire is protected from the normal game's sunlight penalties exactly as before, now on both versions.

## Moving to RimWorld 1.7

RimWorld 1.7 runs on a new engine, so mods written for 1.6 need their own 1.7 build. Clothed Vampires now has both, built from the same code. It needed no code changes for 1.7. Players on 1.6 notice no difference, and players on 1.7 get a build made for it.

## What we tested

All testing was on **RimWorld 1.7**, with your full mod list: Vanilla Expanded Framework, Alpha Genes, every Big and Small mod, UnderWhere, Undergarments Core and the rest. The test pawn was Dmitry, made a sanguophage with the developer tools. In this mod list his sanguophage genes include **mild** UV sensitivity: a -6 "sunlight sensitivity" mood penalty and 90% walking speed in the sun.

**Clothing.** Each check was made outdoors in clear daylight:

| What Dmitry wore | Mood penalty | Walking speed |
|---|---|---|
| Nothing | -6 | 3.89 (slowed) |
| Shirt only | -6 | 3.89 (slowed) |
| Shirt and pants | none | 4.32 (full speed) |
| Duster only | none | 4.32 (full speed) |

4.32 is exactly 3.89 with the sun's 90% removed, so the slowdown is gone completely, not just reduced.

**Underwear.** Underwear on its own never protected him, even when it covered both torso and legs:

| What Dmitry wore | Mood penalty | Walking speed |
|---|---|---|
| UnderWhere tanktop and boxers | -6 | 3.90 (slowed) |
| Undergarments Core "Basic undergarments" | -6 | 3.89 (slowed) |
| Basic undergarments under a shirt and pants | none | 4.32 (full speed) |

**Saving and loading.** We saved the game, loaded it again, and Dmitry was still protected, with no errors from the mod.

**Loading cleanly.** The mod loaded with no errors of its own three ways on 1.7: with your full mod list, with nothing but Harmony and the official expansions, and when loading the save.

**RimWorld 1.6.** We switched Steam back to 1.6 and loaded the same save there, with your larger 1.6 mod list, which includes Combat Extended. It loaded fine, and Dmitry in undergarments, shirt and pants was still fully protected.

## Issues we found

No problems with the mod itself. A few things came up while testing:

- **The mood list updates a little late.** After a clothing change, the "sunlight sensitivity" line takes a moment to appear or disappear, while walking speed changes straight away. The first shirt-only check looked like a failure for that reason. Waiting about 30 seconds of game time showed the penalty correctly, and the test instructions now say to wait.
- **A warning about a missing gene when saving.** This came from changing Dmitry into a sanguophage with the developer tools, which left one of his traits pointing at a gene that no longer exists. It's not from Clothed Vampires and doesn't happen in normal play.
- **A Steam Workshop item with no folder.** Every launch logs an error about Workshop item 3807619463, which is subscribed but missing from disk. It isn't this mod. Unsubscribing from it should clear the error.

## Decisions made

- **1.7 support and the documents come first,** before the Alpha Genes fix, so the fix is built on the new setup.
- **Test with the full mod list.** You pointed out that the original problem happened with a large mod list, so a small one could hide exactly the kind of problem we're looking for. All the gameplay tests used your full list.
- **Keep one quick load with almost no mods,** only to prove the mod doesn't secretly depend on another one.
- **Skip the roof check.** It only tests the normal game's own behavior under a roof, which the mod doesn't touch.
- **Reuse today's save for the old-save check,** since there was no older save to hand. The mod stores nothing in saves, so it's an equivalent test.
- **Keep the Workshop link file in the project,** so the mod's Steam page link can't get lost.
- **Next feature: clothing protection for Alpha Genes' knockout and burns, with settings.** You chose four on/off switches (slowness, mood, knockout, burns), all on by default, plus a "Genes only / Absolute" choice for whether clothing blocks only gene-caused sunlight effects or every sunlight effect.

## Where this leaves it

Clothed Vampires now works on both RimWorld 1.6 and 1.7, and everything above was tested in a real game. It's ready to publish as an update whenever you like.

Not tested this round:

- **Intense UV sensitivity** (the stronger vanilla gene). Dmitry's genes had the mild one. Both use the same game check, so it should behave the same, but it hasn't been seen in a game yet.
- **Standing under a roof** (skipped, see above).

**Next:** the Alpha Genes fix. Clothing will block vicious UV sensitivity's knockout and lethal UV sensitivity's burns, with the settings you chose.
